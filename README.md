# React Cafe

Homework 2 for the React and Client-Side SPA Architecture course.

A feedback widget for Sip Happens Café that allows users to rate the service and view feedback statistics.

## Technologies

- React
- TypeScript
- Vite
- CSS Modules
- modern-normalize
- Prettier
- ESLint

## Features

- Voting: Good, Neutral, Bad
- Total feedback count
- Positive feedback percentage
- Reset feedback
- Notification when there is no feedback

## Installation and usage

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## Code quality

```bash
npm run format
npm run lint
```

## Build

```bash
npm run build
```
